# Changelog

## [1.1.0] - 2026-05-05

### Added
- Configurable target closed status setting in plugin configuration
- Admin can now choose which closed status the fast-close button uses
- Falls back to first closed status by position when no specific status is configured
- Polish and English translations for the new setting

## [1.0.0] - Initial release

### Added
- One-click "Close" button on issue views
- Workflow-aware authorization (button only shows if user can transition to closed status)
- Polish and English translations
